# 2D para 3D: plano de execução

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Trocar o Criador de logos pelo "2D para 3D": imagem → peça sem base, partes lado a lado com cor e
altura por parte, 3D com mesa e cotas, qualidade máxima.

**Architecture:** Geometria nova em `modelos/relevo.js` (Manifold), sobre o mesmo mapa de cores
(`mapa-logo.js`) e vetorizador de hoje. A tela `logo` é enxugada e ganha o balão da parte. `previa3d.js`
ganha mesa e cotas. Exportação, custo, fatiador e Meus modelos reaproveitam `modelos-acoes.js`/`modelos-ui.js`.

**Tech Stack:** Electron, ES modules (esbuild), Manifold WASM, three.js, vitest (+ happy-dom).

**Spec:** `docs/superpowers/specs/2026-11-16-2d-para-3d-design.md`

## Global Constraints

- Tudo em pt-BR; interface mínima; nada de "Em breve"; só as 14 cores prontas (`CORES_LOGO`).
- Todo objeto Manifold dentro de `comEscopo(M, (guardar) => …)` e passado por `guardar(...)`.
- Malhas fechadas e orientadas (`malhaDoSolido`).
- Tela continua com id `logo`; título no catálogo: **"2D para 3D"**.
- Altura das partes: padrão **3 mm**, limite **2 a 10 mm**, passo **0,2 mm**.
- Largura padrão **100 mm**; ilha menor que **1,5 mm²** vira a parte vizinha (sem vizinha: some).
- Mapa até **2000 px** no lado maior; Bézier com erro ≤ **0,15 px**; corda ≤ **0,05 mm** na peça final.
- Mesa da Kobra X: **260 × 260 mm**, grade de 10 mm. Cota X vermelha, Y verde, mm com 2 casas.
- Sem AMS: degraus por cor, cor de maior área embaixo, primeira faixa = altura padrão, cada faixa seguinte
  **+1,0 mm** (chamada do plano), pausa no começo de cada faixa (`camadaDaTroca`).
- Argola: opcional, **desligada** por padrão; altura padrão das partes; cor da parte em que encosta.
- Modelos antigos do Criador de logos continuam abrindo; nenhum dado salvo é apagado.
- Sem AMS é escolhido na hora de exportar/abrir no fatiador (pergunta "Como você vai imprimir?"), com a
  ordem padrão. Trocar a ordem das cores na tela fica fora desta versão (desvio do desenho, aceito pelo Pedro
  ao aprovar o plano).
- Release só local (sem push/release) até o Pedro dizer "pode lançar". Versão **0.53.0**.
- Não mexer no programa antes do "comece" do Pedro.

## Review Focus

1. Partes vizinhas com bordas idênticas: nenhuma fresta nem sobreposição no fatiador (teste de partição).
2. Imagem só com fundo (ou tudo apagado pela borracha): mensagem em pt-BR, nada trava (teste em Task 1).
3. Escolha de parte que deixa de existir depois de mudar tamanho/cores: descartada sem erro (Task 4).
4. Modelo antigo (versão 2) com base/argola/relevo abre e gera peça sem base (Task 6).
5. Imagem muito grande (ex.: 6000 px) não estoura memória nem passa de ~2 s para gerar (Task 2, mapa limitado a 2000 px).
